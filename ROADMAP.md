# Roadmap

The roadmap is limited to the statement-analysis workflow; it does not cover budgeting, investing, goals, account aggregation, or banking integrations.

## Near term

- Add automated regression fixtures for supported CSV/XLS/XLSX statement layouts and transaction-classification edge cases.
- Add service-level tests for category totals, refunds, transfers, exclusion accounting, and forecast inputs.
- Review chart accessibility, small-screen rendering, and empty-state consistency across all tabs.

## Later

- Define explicit data contracts for normalized transactions and analysis outputs.
- Add performance profiling for large statements and optimize only measured bottlenecks.
- Establish versioned release notes and compatibility checks for the existing statement upload formats.
